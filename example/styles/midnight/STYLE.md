# Midnight

Dark navy with a soft radial glow, off-white type and an orange accent bar on the left edge. System sans (Helvetica Neue / Arial), so nothing to download. The repo's default style.

Use `.title` for the headline, `.subtitle` for its muted second line, `.line` for rows that animate in, `.accent` to highlight a word. Avoid more than ~6 lines per scene at the default sizes.
